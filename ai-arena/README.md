# MODEL / CLASH 本地双人样本

打开 `index.html` 即可玩，资源全部在本地，无需安装依赖或接入账号。
也可执行 `node server.cjs`，访问 http://127.0.0.1:4173 。服务只监听本机。

## 操作

| 动作 | P1 | P2 |
| --- | --- | --- |
| 格斗移动 / 蹲下 / 跳跃 | A D / S / W | 左右 / 下 / 上 |
| 轻击 / 重击 | J / K | 1 / 2 |
| 特殊技 / 超必杀 | U / I | 4 / 5 |
| 突进 / 防御 | L / O | 3 / 6 |
| 竞速前后左右 | W S A D | 方向键 |
| 竞速跳跃 / 翻滚 | J / K | 1 / 2 |
| 暂停 / 返回 | P / Esc | 共用 |

P2 数字支持数字小键盘，也支持主键盘数字行。建议英文输入法。
两个标准映射手柄：左摇杆移动、A 跳跃、X 轻击、Y 重击、B 技能、RB 突进、LB 防御、RT 必杀；竞速 A 跳、B 翻滚。实际设备兼容尚需实机测试。
触屏设备会出现两组触控按钮，推荐横屏；主验收场景是电脑同机双人。

## 本轮交付

- 四个原创建模风格的程序绘制 AI 角色。GPT：突进连段；DeepSeek：飞行道具；Claude：限时反制；Gemini：二段跳与空中技能。
- 格斗：固定 60 Hz、前摇/有效/后摇、攻击与受击框、空地动作、防御资源、命中停顿、连段递减、击倒保护、三局两胜和回合重置。
- 竞速：双人分屏自由移动，旋转杆、移动碰撞柱、浮台、缺口、加速带，顺序检查点、跌落复位、细分帧冲线判定。
- 掉焦自动暂停、可选合成命中音、真实判定框显示、双方重赛与保存对局输入记录。
- `DESIGN.md` 梳理产品、模型角色、榜单用途与商用/比赛门槛。
- `model-design-brief.md` 是给各模型的统一委托模板，后续可用真实模型回复替换代拟方案。

## 来源说明

本次四角色方案由当前 GPT/Codex 会话制作。DeepSeek、Claude、Gemini 尚未由对应模型提交。品牌名用于概念讨论，形象是本项目原创概念，不表示官方联名。
没有下载、逆向或复用拳皇、死神 VS 火影、蛋仔派对的代码、美术、角色或音频。REA 已研究，未安装；5DPLAY 已有公开工程，本轮不需要二进制逆向。

## 代码结构

- `fight.js`：无 UI 依赖的格斗模拟，导出角色数据与逐招帧表。
- `race.js`：无 UI 依赖的竞速模拟、关卡和碰撞。
- `app.js`：选角、输入、固定步长循环、暂停、结果与对局记录。
- `render.js`：原创角色与场景绘制、格斗 HUD、竞速透视分屏。
- `tests/`：核心判定回归、确定性与整条赛道通关验证。
- `replay.cjs`：重放保存的输入记录并打印结果，不依赖图形界面。

## 验证

执行 `node --test tests/*.test.cjs` 跑规则测试；执行 `node tests/course-run.cjs` 跑完整竞速输入路线；执行 `node replay.cjs 路径/对局记录.json` 复算保存结果。
本轮 14 项格斗规则和 15 项竞速规则测试通过。整条赛道测试可完成三检查点并冲线。浏览器完成双方独立移动、命中扣血、选角切换、竞速镜头、跳跃和暂停检查，未见控制台错误。

## 当前限制与下一轮

这是可玩验证样本，不能标为可商用或比赛级成品。角色图形仍为程序骨架；尚无正式逐帧美术动画、完整音效、训练模式、完整观战回放 UI、真实外部模型角色投稿、真人平衡数据、真机手柄/多点触控矩阵或网络联机。竞速角色共用能力，专属技能还在提案阶段。

优先下一轮：两名真人每角色组合实玩 → 收集招式可读性/压制问题 → 帧表与碰撞微调 → 对应模型角色投稿 → 训练与回放工具 → 正式美术。赛事数值必须冻结版本，不随模型榜单自动变化。

## 模型提案校验

`node validate-proposal.cjs proposal.json` 检查委托模板输出的招式范围、资源消耗、判定框、反制方式与白名单机制。通过仅代表数据可进入审查，不自动加载到对战，也不证明模型来源或角色平衡。原模型回复和来源记录仍须另行保留。本轮另有 2 项提案校验测试。
